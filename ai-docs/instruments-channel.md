# 乐器频道功能实现文档

## 任务概述

在首页添加乐器频道功能，包含4个分类共20种乐器，用户点击乐器卡片可自动搜索相关音乐。

## 实现时间

2024年（当前版本）

## 功能需求

### 分类结构

1. **流行入门推荐** (🎵)
   - Acoustic Guitar（木吉他）- 旋律与伴奏的完美平衡
   - Keyboard（电子琴）- 易上手，适合编曲与作曲
   - Cajón（卡洪鼓）- 便携打击乐，节奏感强
   - Ukulele（尤克里里）- 小巧可爱，入门首选
   - Harmonica（口琴）- 随身乐器，适合民谣与布鲁斯

2. **经典原声乐器** (🎻)
   - Violin（小提琴）- 优雅且富有表现力
   - Cello（大提琴）- 音色深沉，极具感染力
   - Flute（长笛）- 清澈空灵的音色
   - Piano（钢琴）- 乐理与音乐基础的核心乐器
   - Classical Guitar（古典吉他）- 指弹与独奏之美

3. **现代乐队必备** (🥁)
   - Electric Guitar（电吉他）- 摇滚与流行的灵魂
   - Bass Guitar（电贝司）- 节奏与低频的支撑
   - Drum Set（架子鼓）- 音乐节奏的心脏
   - Synthesizer（合成器）- 无限音色创造的工具
   - Microphone（麦克风）- 声音艺术的核心

4. **世界民族乐器精选** (🌏)
   - Erhu（二胡）- 东方的灵魂之音
   - Djembe（非洲手鼓）- 狂野的节奏力量
   - Sitar（锡塔尔琴）- 印度古典代表
   - Pan Flute（排箫）- 来自安第斯山的风之声
   - Shamisen（三味线）- 日本传统弦乐

#### 1. 数据模型


#### 2. 渲染逻辑

- 使用 `renderInstruments()` 函数动态生成乐器频道
- 按分类组织显示，每个分类包含标题和乐器网格
- 每个乐器卡片显示表情符号、英文名、中文名和描述

#### 3. 搜索功能

- 点击乐器卡片时，自动填充搜索框（英文名 + 中文名）
- 调用 `handleSearch()` 函数执行搜索
- 清空艺术家输入框，确保搜索准确性

#### 4. 样式设计

- 响应式网格布局，适配不同屏幕尺寸
- 卡片悬停效果，提升交互体验
- 使用 CSS 变量，支持主题切换
- 移动端优化，确保良好的移动体验

## 用户体验

### 交互流程

1. 用户访问首页，看到乐器频道
2. 浏览4个分类，查看20种乐器
3. 点击感兴趣的乐器卡片
4. 系统自动搜索该乐器相关音乐
5. 浏览搜索结果并播放

### 视觉设计

- 清晰的分类标题和图标
- 每个乐器卡片包含表情符号、名称和描述
- 悬停时卡片上浮，提供视觉反馈
- 响应式布局，适配各种设备
